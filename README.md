# Abstract-Chain-XP-Tracker-System
As a content creator on X, most of my content revolves around stats-based content. So yeah, I vibe-coded a system that actually solves my main hardcore problems. Because of this system, my content creation time has reduced from 7 hours to just 2 hours. I built this mainly to increase my productivity and focus on other important work as well.

What this system does (in simple words)?

This system takes data that is entered manually. After receiving the data, it stores it properly. The developer can also add profile pictures (PFPs) next to the usernames. After that, the system generates a ready-to-use text format that can be directly posted on X.

Additionally, the system automatically generates a packed circle chart based on the data. The developer can download this chart with a transparent background, and it can be used on other devices or in other designs easily.
